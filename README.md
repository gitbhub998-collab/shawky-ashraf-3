# Shawqy Ashraf Hussein — Portfolio

Professional portfolio for Shawqy Ashraf Hussein, a third-year Railway Technology student at October Technological University and CNC engineering specialist. The page presents his education, CNC and hydraulic experience, technical training, software skills, registered patent, and engineering projects.

The site is built with static HTML, CSS and JavaScript. Profile photographs and the railway background are stored in `assets/`; project images are stored in `assets/projects/`. The `favicon.svg` file contains the SH monogram.

## Deploy to Vercel

Import the repository into Vercel using the **Other** framework preset. Leave the build command empty and set the output directory to `.`. The included `vercel.json` contains these settings; no build step or dependencies are required.
